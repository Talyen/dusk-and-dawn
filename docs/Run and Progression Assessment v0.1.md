# Run and progression assessment

Reviewed the game design v0.2, later status and flow reviews, implemented rules, and runtime at `3c0420c`. Ryan's later decision for distinct antihero classes supersedes the original proposal to avoid a class screen. Existing values remain playtest proposals.

| Design area               | Current implementation and limits                                                                                                                                                                                                          |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Fight and run             | Three regular fights, an elite and a boss; health and deck carry over, while fight-local zones, statuses and facing reset. Rewards add one pair or can be skipped.                                                                         |
| Route and rest            | The midpoint offers healing or removal; two optional route points offer previewed combat, rest or an event. Mirror Exchange can be cancelled before commitment. The map is intentionally small.                                            |
| Starting choices          | Three antiheroes have different kits and passives; one run relic and a light or unlocked dark starting orientation can be selected. Existing class and relic saves retain their recorded rules where versioned.                            |
| Persistence               | Accepted actions, including committed hidden-card inspections, save their state and random stream. Recovery uses a retained save. Reward, route, rest, victory and defeat are resumable; progression and collection are stored separately. |
| Progression               | Qualifying expeditions expand card and enemy pools through three tiers; the first unlocks Nocturne. A run captures its own pool tier, so later unlocks affect future runs. There is no permanent damage or HP tree.                        |
| Information for decisions | Card, enemy, deck, intent and route inspection is contextual. A Hush face now forecasts the current action if Hushed, including immediate reactive-trait suppression.                                                                      |

The design mentions future unlockable starting decks and cosmetics without defining their content, unlock conditions, presentation or how they relate to the approved classes. More expansive progression, additional encounters or permanent rewards would require product direction; they are not implied by the existing tier experiment. The current system reaches its maximum pool tier after two qualifying expeditions, so long-term progression beyond that remains an open product question. Audio assets are also not specified or registered. Bless/Curse scaling and Freeze thaw remain open and were not changed.

The Hush forecast fills a specified combat-choice gap without changing rules. It uses the suppressed base action with current Bless/Curse, notes a skipped ability or still-Frozen action, and reports immediately suppressed reactive damage or Reflect. It accounts for older Witch passives, Seraph and Ashen Seal Ward, and lethal Burn/Poison before the action. It is a forecast of the present state; subsequent card plays can change it. Pointer, keyboard and touch inspection do not spend mana, and an invalid Hush still explains its restriction. Tests cover attacks with traits and extra hits, a non-attack ability, Ward bypass, reactive traits, Freeze, legacy passives, status lethality and the zero-mana inspection boundary.

Visual review compared the original and candidate Mourning Tree encounter with the same Witch hand and Curse 2 at 1280×720, English, default scale and motion; the new line appeared only in Silence's contextual tooltip. At 390×844 and 320×480, the tooltip remained readable; as with other long card inspections, the smallest view overlays the board while open. In a controlled browser play, inspecting Silence forecast 5 Growth without the Curse rider, keyboard activation played it directly, and ending the turn dealt 5 HP with no new Curse. This is a focused encounter, not a full-run balance study.
