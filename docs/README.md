# Design and review index

The playable prototype and its current implementation live in `src/`; these documents retain the design rationale, catalogues and evidence that informed it. A review's date, proposed status and validation limits are part of that evidence. Do not treat historical claims about missing runtime or unperformed tests as a current project status.

For a source-backed overview of current run and combat behavior, start with [implemented rules](GAME_RULES.md). The design documents below are not a substitute for that implementation.
