# Prepared artwork provenance

The manifest selects artwork from the user's Dusk & Dawn project folders in Google Drive. Each source is identified in the manifest; the source SHA-256 and derived file hash are recorded in `receipt.json`. Card and enemy sources were checked against the project's artwork coverage records before preparation. The three hero images were selected from the project's Hero Artwork studies and prepared from those originals.

The user requested this project artwork be used in the game and in a Vercel playtest preview. That request authorizes this project use. Independent authorship or ownership documentation was not available in the repository; no broader license or distribution rights are asserted here.
